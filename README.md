# wazuh-stack — single-node Wazuh deployment for the agentic SOC

Production-proven docker compose for a single-node Wazuh stack
(manager + indexer + dashboard + wazuh-wui), wired into the agentic
SOC: the realtime ingest service, the SOC gateway token check, and the
`agentic-soc-send` integratord plugin that ships alert payloads to the
reports mailbox.

Part of the [agentic SOC build](https://github.com/dmrobbi/soc-openclaw)
alongside [laya-control](https://github.com/dmrobbi/laya-control) and
[stig-baselines](https://github.com/dmrobbi/stig-baselines).

## Layout

| path | purpose |
|---|---|
| `docker-compose.yml` | the live stack: manager, indexer, dashboard, wazuh-wui + env wiring for the ingest/mail paths |
| `docker-compose-official.yml` | the pristine upstream compose, kept as reference |
| `config.yml` | cert-generation node map (all loopback) |
| `config/wazuh_cluster/wazuh_manager.conf` | manager config (cluster key placeholder — generate your own) |
| `config/wazuh_dashboard.yml` | dashboard config |
| `config/wazuh_manager_extra.conf` | extra ossec.conf entries merged via volume mount (JSON logging) |
| `integrations/` | the `agentic-soc-send` integratord wrapper + implementation |
| `generate-indexer-certs.sh`, `wazuh-certs-tool.sh` | cert generation (Wazuh's official tool) |
| `.env.example` | every credential the stack expects |

## Deploy flow (summary)

1. `./wazuh-certs-tool.sh --config-file config.yml` — generate node certs.
2. Lay out `config/` as the compose volumes expect (certs under
   `config/wazuh_indexer_ssl_certs/` are generated by the tool — never commit them).
3. `cp .env.example .env` and fill in the passwords + token.
4. `docker-compose up -d` (certs first: indexer → manager → dashboard).
5. Agents connect to the manager's Tailscale/LAN address over 1514.

## Secrets

Everything secret is environment-injected and fails fast if unset —
this repo never contains a plaintext credential. `./secrets/` is
gitignored: create your own `reports-mailbox.env` there with the SMTP
values the send integration reads at runtime.

Indexer password rotation: the indexer and dashboard indexes store
hashed credentials — use the Wazuh indexer credential rotation flow
(regenerate + `securityadmin` reload) rather than editing compose values
in place; the compose values here are only the bootstrap passwords.
